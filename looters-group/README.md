# Looters Group

Umbrella site for Looters Computas, Looters Apparel, and Looters Software.

Sales stay on [Trade Me](https://www.trademe.co.nz). This site is the shopfront.

## Go live (free)

This app is built for **Vercel** (free hobby plan).

1. Push this repo to GitHub (see below).
2. Sign in at [vercel.com](https://vercel.com) with GitHub.
3. **Add New… → Project** → pick `looters-group`.
4. Deploy. Leave the defaults. You get a URL like `looters-group.vercel.app`.

To keep [lootzy-storefront.onrender.com](https://lootzy-storefront.onrender.com/) as the public address, after Vercel is live add a redirect on that Render service to the Vercel URL.
