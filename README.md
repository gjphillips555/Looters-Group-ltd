# Looters Group

Umbrella site for Looters Computas, Looters Apparel, and Looters Software.

Sales stay on [Trade Me](https://www.trademe.co.nz). This site is the shopfront.

## Go live (free)

Built for **Vercel** (Hobby). Repo: `gjphillips555/Looters-Group-ltd`.

To pick up Tradevine labels (DSKTP, LPTOP, CMPNT, **APARL**):

Vercel → Project → Settings → Environment Variables:

- `TRADEVINE_CONSUMER_KEY`
- `TRADEVINE_CONSUMER_SECRET`
- `TRADEVINE_ACCESS_TOKEN`
- `TRADEVINE_ACCESS_TOKEN_SECRET`

Same values as the old lootzy-storefront Render service. APARL listings only appear on Apparel pages.
